# История версий

## v1.0.0

Первый подготовленный выпуск для GitHub Pages. Ресурсы разделены по assets/css, assets/js и assets/icons, инструкции — docs, проверки — scripts. Встроенные стили вынесены в base.css.

- Календарь и повторяющийся график смен.
- Расчёт по ставке с фиксированной надбавкой за день.
- Русский и польский интерфейс, PLN и BYN.
- Копилка: несколько целей, начальная сумма, пополнения и снятия.
- Резервные копии с совместимостью с прежними версиями.
- Стеклянное оформление и анимации без подъёма элементов при наведении.

Проверки при упаковке: синтаксис JavaScript, наличие локальных ресурсов, расчёт дневной и ночной смены, надбавки, баланс копилки и совместимость резервных копий. Полная проверка интерфейса в браузере и реальная публикация на GitHub в рамках подготовки архива не выполнялись.
