# Godzivo

**Смены, заработок и личная копилка.**

Личное веб-приложение для учёта рабочего времени и накоплений. Работает прямо в браузере, без установки зависимостей и регистрации. Интерфейс на русском и польском, валюты PLN и BYN.

## Возможности

- Календарь дневных и ночных смен, выходных, отпуска и больничного.
- Время начала и конца, в том числе переход через полночь.
- Повторяющийся график с заданным числом рабочих и выходных дней.
- Почасовая ставка и фиксированная надбавка за выбранный день.
- Статусы «Запланировано» и «Отработано», заработанное и прогноз за месяц.
- Несколько целей накоплений: начальная сумма, пополнения, снятия, заметки и шкала прогресса.
- Сохранение в браузере и экспорт/импорт резервной копии JSON.
- Стеклянный интерфейс, плавные переходы и поддержка уменьшения движения.
- Иконка и режим запуска с экрана «Домой» на iPhone.

## Первый запуск

Откройте **[START_HERE_RU.md](docs/START_HERE_RU.md)** — там пошаговая загрузка на GitHub и включение GitHub Pages.

После публикации укажите страну и ставку в настройках. Нажмите день в календаре, заполните смену, при необходимости укажите надбавку. Для накоплений откройте вкладку «Копилка».

## Как считается заработок

Сумма за день = длительность смены × сохранённая ставка + надбавка за день.

Заработанное включает записи со статусом «Отработано»; прогноз — все записи месяца. Выбор PLN/BYN разделяет итоги по валюте. Длительность без вычета перерывов, автоматической ночной доплаты нет. Отпуск и больничный сами по себе не начисляют оплату; заданная вручную надбавка учитывается. Каждая запись сохраняет свою ставку: изменение настройки не переписывает ранее добавленные смены.

Копилка учитывается вручную и отдельно от зарплаты. Цель не получает деньги автоматически после смены. Остаток = начальная сумма + пополнения − снятия.

## Хранение и перенос данных

Данные хранятся в localStorage этого браузера. Серверной базы, аккаунтов и синхронизации между устройствами нет. Очистка данных сайта удаляет записи; регулярно скачивайте резервную копию в настройках.

**При переходе со старого адреса на GitHub Pages:** скачайте резервную копию в настройках старого приложения, откройте новый адрес и восстановите её там. Данные автоматически между адресами не переезжают. GitHub не должен содержать ваши личные JSON-копии.

Добавление на экран «Домой» не означает полноценную поддержку офлайн: service worker в этой версии отсутствует.

## Локальная разработка

Достаточно статического HTTP-сервера. Например, с установленным Python:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Сборки и установки npm-пакетов нет. Для проверки проекта с установленным Node.js:

```sh
npm run check
```

Проверяются синтаксис JavaScript, пути к ресурсам и манифест. Проверка не заменяет визуальный тест в браузере.
 Для публикации загружайте изменённые файлы в ветку `main`.

## Выпуск обновлений

1. Скачайте резервную копию данных.
2. Проверьте изменения локально.
3. Обновите изменённые файлы в репозитории и сохраните commit.
4. GitHub Pages автоматически опубликует содержимое выбранной ветки.
5. Проверьте новый адрес на телефоне и компьютере.
6. Для именованного выпуска создайте GitHub Release и новый тег, например `v1.0.1`. Тег отмечает версию, а сайт обновляется из `main` независимо от Release.

Не переименовывайте ключ localStorage `godzivo` без миграции. Изменения структуры резервных копий должны сохранять совместимость со старыми данными.

## Текущие ограничения

Приложение считает по введённым значениям, не рассчитывает налоговые удержания. Доступна одна запись на дату. Нет обмена валют. При переходе через полночь вся смена относится к дате начала; переход на летнее/зимнее время отдельно не учитывается. Возможны отличия поддержки стеклянного эффекта между браузерами.

Исходный пакет: **v1.0.0**. Это исходники текущей версии Godzivo с копилкой; служебные файлы прежнего хостинга не включены.
